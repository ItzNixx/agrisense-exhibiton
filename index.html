// What it does
🌡️
Temperature & Humidity

DHT22 sensor provides accurate temperature readings every 5 seconds. The fan relay activates automatically when your plant's optimal range is exceeded.

💡
Light Intensity

LDR photoresistor converts raw ADC readings to a 0–100 % intensity scale. Grow lights switch on automatically when ambient light falls below threshold.

💧
Soil Moisture

Capacitive soil sensor maps dry/wet extremes to a clean percentage. The pump relay triggers when soil drops below the plant's moisture minimum.

☁️
Firebase Cloud Sync

All sensor readings and actuator states stream to Firebase Realtime Database every 5 seconds — with graceful offline fallback when WiFi is unavailable.

🌿
Plant Profiles

Switch between Pepper, Mint, Parsley, and Thyme profiles. Each has tailored temperature, light, and moisture ranges. Change profile live from this dashboard.

📟
LCD Local Display

16×2 I²C LCD shows plant name, actuator icons, and live sensor readings locally — fully functional without internet access.
